試合パート（監督ビューア）で**選手交代が行われた瞬間にカットシーンを1枚挿入する**ための計画。
画像は**ユーザーが用意**し、表示・オーバーレイ・トリガーは Claude が実装する（役割分担は [CUTSCENE_ART_GUIDE.md](CUTSCENE_ART_GUIDE.md) と同じ）。

- 対象：デイリーリーグ（および監督ビューア全般）の試合中の交代
  - **相手監督AIの交代**（`_mvOpponentSub`）
  - **自チームの交代**（采配モーダル → HT / 継続時に適用）
- 交代イベントは既に `window._mvMatchSubs`（`{chanceIdx, time, text, out, in, side, teamColor}`）に記録済み（テキストログ機能で実装済み）。カットシーンはこの情報で駆動する。

## 1. ユーザーが用意する画像（素材の仕様）

**既存カットシーン規約（[CUTSCENE_ART_GUIDE.md](CUTSCENE_ART_GUIDE.md) §2）に完全準拠**。以下だけ満たせば、後処理（140px/28色ピクセル化・キット色展開）は既存パイプライン（`gen.js`/`pixelate.js`/`recolor.js`）が自動でやる。

| 項目 | 値 |
|---|---|
| モーメントID | **`sub`**（マニフェスト `moment: "sub"`） |
| 構図比率 | **3:4 縦**（他カットシーンと共通） |
| 生成解像度 | 高解像度（1024px級）で生成 → 後処理で横140pxへ |
| 形式 | **PNG**・フルブリード（透過不要） |
| セーフゾーン | **上18% / 下20%** は HUD/名前オーバーレイが乗る。**主役は中央**、上下に余白 |
| キット色 | **赤ベース1枚**を用意 → `recolor.js` が blue/skyblue/white/yellow/orange/green/dark に自動展開（他モーメントと同方式） |
| 文字・数字 | **描かない**（OUT↓/IN↑の選手名・矢印・時刻は実行時にコードが重ねる） |
| IP規約 | 匿名の汎用フェイス・架空ソリッドキット・ロゴ無し（§1厳守） |

**絵の内容（案）**：以下いずれか、または組み合わせ。ピクセルアート・フラッドライトのピッチ・ボケ観客。
- (A) **第4審判の電光交代ボード**を掲げるシーン（ボードは無地＝数字は実行時に重ねる）
- (B) **タッチライン際で入れ替わる2選手**（1人が退き＝うつむき/歩き、1人が入る＝ジョグで入場・ハイタッチ）
- (C) ベンチから立ち上がり手袋・すね当てを直す**投入直前の選手**

推奨は **(B)**（交代=入れ替わりが直感的・キット色が主役で recolor が映える）。

**納品先**：`tools/art/incoming/` に置く → `gen.js` で後処理 → `img/cutscenes/sub_<kit>_01.png` として出荷 → マニフェスト `sub` 登録。

## 2. Claude が実装する側（画像が来たら）

### 2-1. マニフェスト登録
- `tools/art/cutscenes.manifest.json` と `js/cutscene.js` の `CUTSCENE_MANIFEST` に `moment: "sub"`（kit別）を追加。

### 2-2. 描画関数 `_renderSubScene(outName, inName, teamColor, kit)`（js/cutscene.js）
- ベースは既存の**フルフレーム系**（`cs-fullframe` = `object-fit:contain`、PENALTY!/GOAL!! と同じ扱い）で 360×480 に描画。
- キット色は `_colorBucket(teamColor)` → 該当 `sub_<kit>_01.png` を選択（既存の色バケット流用）。
- オーバーレイ（実行時・上から重ねる）：
  - 上部セーフゾーン：**「交代 / SUBSTITUTION」**ラベル＋時刻（`time`）
  - 中央下：**`⬇ OUT名`（赤系）** と **`⬆ IN名`（緑系）** を2行で。矢印はコード描画。
  - チームカラーのアクセント帯（自/相手が一目で分かるよう `side` で左右 or 色分け）。

### 2-3. トリガー（js/manager-match.js）
- 交代が**適用された瞬間**にカットシーンを1ビート挿入する。
  - 相手AI：`_mvOpponentSub` で `applyDecision` 成功後。
  - 自チーム：`_mvManagerHTKickoff` / 継続時の `_pendingSubLog` 反映後。
- 流れ：自動再生を一旦停止 → `screen-game` のカットイン領域に `_renderSubScene` を全画面表示（≈1.8〜2.2s）→ 既存の采配パネル / キックオフへ続行。
  - HT交代は「ハーフタイムモーダルを閉じて後半キックオフ」の直前に差し込む。
  - 得点直後の交代（相手AI）は「ゴール余韻カット → 交代カット → 采配パネル」の順。
- テンポ定数（表示秒数）は他カットシーン同様に調整可能な数値で持つ。

### 2-4. スコープ・不可侵
- **表示層のみ**。エンジン（`simulateChance`・デュエル解決）には触れない。
- 交代自体のロジック（`applyDecision` / 相手AI）は既存のまま。カットシーンは「見せ方」だけ。
- 回帰は harness（playMatch経由＝カット無関与）で緑を維持。
