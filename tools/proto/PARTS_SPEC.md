# 選手ポートレート・PNGパーツ 仕様書（PT-04）

モジュラー・ポートレートの「実PNGパーツ」方式の**契約（スロット仕様）**。
同じ7フィールド（肌×髪型×髪色×輪郭×目/眉×口×髭）・同じ合成エンジンのまま、中身を手描き/AIのPNGに差し替える。
確認環境：`tools/proto/portrait-lab.html`（`parts/` にPNGを置くと自動でその部位だけ手続き描画を上書き。無い部位はフォールバック）。

---

## 1. キャンバスと座標（すべての部位で共通）

- **キャンバス比 = 6:7（縦長）**。内部の正準グリッド = **72(W) × 84(H)**。
- **入稿サイズ = グリッド×10 = 720 × 840 の透過PNG**（作画はこの解像度・実行時に縮小）。
- **全部位は同じ720×840フレームに描き、下敷き [`parts/_guide.png`](parts/_guide.png) のランドマークに必ず合わせる**（部位ごとに位置がズレると合成が崩れる）。
- 背景は**ベタ塗りのマゼンタ `#FF00FF`**（透明/チェッカーにしない）。→ Claude がその色をキーで抜いて透過化する。**白目・ハイライトなど白い部分が背景と同色で消えるのを防ぐため必須**。その部位以外は描かない（例：髪パーツに顔を描かない）。
- **向き＝3/4ビューで全32枚を統一**（**耳が左に見え・右頬がふくらむ側**・約20°）。これが「向きクラス」の第1号（将来ポーズ別に角度を足す土台）。**左右対称ではない**ので、必ずガイド `_guide.png` に重ねて同じ角度で描く。

| 部位 | grid y | px y | 備考 |
|---|---|---|---|
| 生え際/頭頂 | 12 | 120 | 髪のトップ基準 |
| 目線 | 38–45 | 380–450 | 目枠（下記） |
| 鼻先 | 50 | 500 | |
| 口 | 54 | 540 | |

## 1.5 位置は"描いたまま"保持／ガイドは実物の顔から作る（重要）

**位置・サイズは描いたまま保持する（丸ごと配置・後付けのアンカー補正はしない）**。ズレの真因は、目/口を合わせる基準が"実在しない平均顔"だったこと。対策＝**ガイドを実物の `face_oval` から生成**し、目/鼻/口の置き場所を**実際の顔の上**に示す。作り手はその顔の上の正しい位置・サイズで features を描く→背景除去して**丸ごと** 720×840 へ（切り出し・再配置しない）＝描いた通りに登録される。顔アーキタイプごとに features 位置は微妙に違うので、**ガイドは各 face から生成**する。

## 2. レイヤー順（合成エンジンが奥→手前に重ねる）

1. **後髪** `hairback_*`（該当スタイルのみ・リカラー）
2. **ジャージ/襟**（★手続き＝チーム色駆動。**PNG不要**）
3. **肌ベース** `face_*`（頭・耳・首・鼻・頬。**目/眉/口は描かない**・リカラー）
4. **目＋眉** `eyes_*`（フルカラー・リカラーしない）
5. **口** `mouth_*`（フルカラー・リカラーしない）
6. **髭** `beard_*`（該当時のみ・**髪色でリカラー**。口の上・前髪の下＝口髭が上唇に重なり顎髭が口を囲む）
7. **前髪** `hairfront_*`（リカラー）

> ジャージ/襟は選手個人ではなくチーム属性なので、既存の `team_color` で手続き生成し続ける（PNG化しない）。

---

## 3. リカラー（色替え）ルール ← ここが重要

肌トーン（6色）と髪色（10色）は**実行時に色替え**する。だから**1形状につきPNGは1枚でよい**（6×10枚も作らない）。

- **色替え対象（`face_*` / `hairfront_*` / `hairback_*`）**：
  **グレースケール、または任意の単色**で、**陰影（明→暗）だけを描く**。ハイライトは明るく、影は暗く。
  実行時に**輝度を保ったまま**目標色（肌トーン/髪色）へ置換する（色相・彩度だけ差し替え・明暗はPNGのまま）。
  → 作画時の色は何でもよいが、**立体感＝明暗のグラデ**をしっかり入れること。
- **色替えしない（`eyes_*` / `mouth_*`）**：**最終色で描く**（白目・虹彩・ハイライト・眉・唇色など）。
  ※ `face_*` に目鼻口を描くとそこも肌色に染まるので**必ず別レイヤー**にする。

### 4-3. 後髪 `hairback_<id>.png`（4枚・リカラー：髪色／該当スタイルのみ）

### 4-3b. 刈り上げ地肌 `hairfade_<id>.png`（該当スタイルのみ・リカラー：**暗め肌色**）
ツーブロック/フェード/アンダーカット等で**刈り上げた側面の地肌＋短い無精髭**の領域。**髪色ではなく肌色を暗めに（`shade(skin,0.72)`）リカラー**＝地肌トーンに追従（濃い肌なら濃い地肌）。**前髪の下・肌の上**に描き、前髪と同じ変形に連動（同一座標系なので位置調整は前髪と一緒に動く）。対象＝ `fade` 等の刈り上げ系のみ。制作＝1枚の髪アートから、刈り上げの明るい領域を flood-fill で分離して生成（`hairfront_<id>` からは当該領域を透過に）。

### 4-6. 髭 `beard_<id>.png`（4枚・リカラー：髪色／該当選手のみ）
中身＝下顔（口周り・顎・頬の下部）の毛。**グレースケール推奨**（髪と同じ輝度保持リカラーで髪色に追従）。口ランドマーク（y=54）〜顎先（y=57–64）に合わせ、**唇が見える中央は透過**（口レイヤーが下から覗く）。**大多数の選手は髭なし＝`none`（PNG不要・描画スキップ）**なので、量産は控えめでよい。

## 5. 作り方（AI生成＋私の後処理）

1. **下敷き**：`parts/_guide.png` をAIツールのキャンバス/参照に置く。
2. **プロンプト方針**：提示した2枚のポートレートの絵柄（アニメ調ピクセルアート）に合わせ、
   「**指定の部位だけ**を描く／背景・他部位は透明／ガイドのランドマークに合わせる／色替え対象はグレースケールで明暗をしっかり」。
3. **私（Claude）の後処理**：四隅フラッドフィルで透過化・720×840へ整列/トリミング・必要ならピクセル化（`tools/pixelate.js` 系）・ファイル名リネーム。
   （既存のポストプレー画像処理と同じ Pillow パイプラインを流用）
4. **確認**：`tools/proto/parts/` に置いて `portrait-lab.html` をリロード → その部位だけ実PNGに切り替わる。**一部だけでもOK**（未提供の部位は手続きにフォールバックするので、1枚ずつ育てられる）。

## 6. 受け入れ基準

- 32枚が揃うと、全選手・架空選手が**名前ハッシュ由来の6フィールド**で自動的に別人になる。
- 肌6×髪色10のリカラーが破綻しない（明暗が残り、のっぺりしない）。
- 目/眉/口が肌色に染まらない（別レイヤーが効いている）。
- 例2枚の絵柄バーに到達（有機的な陰影・毛束の流れ）。

> この画風・スロットが本番の土台。次段（PT-06）で `face_*` 等を**頭なしボディ＋アンカー**に応用し、動きのスプライトへ載せる。
