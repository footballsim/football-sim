PT-06 方式A（レイヤー）技術検証

固定土台 = pt06_body_bald（白背景キーイング）。差し替えるのは 髪型・肌色・髭の3つのみ（目/口は作らない）。 案1=spikeから髪ピクセル抽出→頭頂整列オーバーレイ / 案2=土台の頭に沿ってCT調ドット髪を手描き。両案を並べて比較。

0) 土台キーイング＋頭アンカー（整列の物差し）

1) 案1: spike から髪抽出 → 頭頂整列オーバーレイ

spikeスプライトの頭部から髪色ピクセルだけをマスク抽出し、spike頭頂→土台頭頂の差分でオフセット整列。ボディのドリフトは使わず髪だけ移植。

2) 案2: 土台の頭に沿ってCT調ドット髪を手描き（3種）

土台の頭アンカー（頭頂/こめかみ/生え際）にプロシージャルなCTドット髪シルエットを描く。整列は定義上完璧・画風は限定パレット＋黒縁で統一。

3) リカラー総合（肌×髪×キット×髭）— 案2ベースで identity 決定論割当

Portrait.featuresFor(longName) の index を使い、SKIN/HAIR 実色へ輝度保持リカラー。キットは赤→チーム色。髭 none/stubble/goatee/full を重畳。
