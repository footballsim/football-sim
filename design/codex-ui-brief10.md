# 依頼（第10弾）：布陣設定画面の再設計 ─ **レイアウトはユーザー承認済み**。配置はその通りに、仕上げだけ整える

## 添付画像の役割
- **`R_lineup_setting_retro.png`** … 現行実装の見た目（**作り直す対象**）
- **`prep_layout_v3.png`** … **承認済みレイアウト**＝ゾーン配置・カード構成はこの通りにする（変えない）
- **`H2_season_end_retro.png`** … **"目標の仕上げ"**＝レトロ・ハイブリッドの見本

## 画面構成（prep_layout_v3 の通り。増やさない・減らさない）

**ヘッダーは無し**（戻るは下部バーにある）。3ゾーン＋下部コマンドバー：

1. **左ゾーン＝控え棚（縦1列・スクロール）**
   - 見出し「控え」＋人数（例: 13人）
   - 1行 = ドット頭＋ポジションチップ＋総合値＋選手名。8行目以降はスクロールで見える（下端に▼ヒント）

2. **中央ゾーン＝ピッチ（主役・いちばん大きく）**
   - 縦向きピッチに先発11人の**ミニカード**。カード = 上段（ポジションチップ＋総合値の数字）／中段（**ドット/ピクセル頭**）／下段（選手名）
   - ポジションチップは**ライン色分け**: GK=赤 / DF=青 / MF=緑 / FW=金
   - バッジ3種を維持: キャプテン**Ⓒ**（金・カード左下）／適正外**!**（橙・右上＋枠も橙）／怪我**🩹**（左上）
   - **表示切替ボタン（1行）**をGK横の空きに: 「数値 ⟳」のように**現在のモード名＋циクルアイコン**だけの小さな1行ボタン（押すと 数値→調子→士気 に切り替わる想定）

3. **右ゾーン＝評価と設定**
   - 上: **「スタメン総合力」パネル**＝大きな数字（例: 76.4）＋増減（▲ +0.8 緑）
   - 下: 設定5行（**システム / 戦術 / キープレイヤー / 要注意 / キャプテン**）。各行 = ラベル＋現在値の横並び1行

4. **下部コマンドバー**: 「← 戻る」「自動編成」「**キックオフ！**（一次アクション・最も強く）」

## 出してはいけないもの
**ヘッダー（戻る・対戦カード・節/ホーム表示）・ケミストリー線・複数編成タブ（1234）・
レーダーチャート・国旗・S/Aランクバッジ・モラル/ブースト・選手の顔写真（写実）・
ポリシー/FORMATION COMBO 等の新機能**。1つも描かないこと。

## 仕上げの指定（H2 と同じUI言語で統一）
- **選手の顔＝ドット/ピクセル頭**（キャプ翼系。写実は使わない）
- **クラブ徽章・アイコン＝ピクセルアート**／**数字・見出し＝ビットマップ寄り**
- **配色＝紺地＋金の二重罫のフラットな限定パレット**（グロス/グラデは抑える）
- **枠・パネル＝チャンク（太め）なドット縁**＋**薄いCRT/ディザ質感**を全体に薄く
- **全画面・スクロールなし・fit-to-screen**（スクロールしてよいのは左の控え棚の中だけ）
- ポジションチップの4色（赤/青/緑/金）は限定パレットに馴染む彩度に落としてよいが、**4ラインが見分けられること**

## 出力
- **landscape 1536×864 を1枚**（image_gen）。
- 配置の意図を **3行以内**で添える。**指定外の情報を足していないこと**も明記すること。
