# 依頼（第7弾・やり直し）：ハーフタイム画面 ─ **情報は今あるものだけ**で作り直す

前回案は**新しい情報を足してしまったため不採用**。今回は **要素を1つも増やさない**こと。

## 添付画像の役割
- **`halftime_current.png`** … **現状の実画面**（作り直す対象）。白いモーダルで縦一列。
- **`H2_season_end_retro.png`** … **"目標の仕上げ"**＝レトロ・ハイブリッドの見本。

## 絶対条件：画面に出してよいのは以下の5つだけ
これ以外は**一切描かない**。ピッチ図・ヒートマップ・攻め筋の内訳・被シュート数・
枠内数・ファール数・疲労ゲージ・カード表示・軽傷表示・士気アイコン・交代枠の残り・
「現在の後半プラン」など、**現状の画面に無いものは足さないこと**。

1. **前半終了時のスコア**（例：🏴 イングランド 0 - 0 ベルギー 🇧🇪）と「ハーフタイム」の見出し
2. **ハーフタイムの采配（3ステップ・順番固定・前を済ませるまで次は開かない）**
   - ①コーチから助言をもらう … 押すと「相手は前半◯◯を◯回仕掛けている。後半はここを潰す。」と結果文が出る
   - ②選手を鼓舞する … 押すと「ロッカールームが沸いた。チーム全体の士気が上がった。」
   - ③選手個別にアドバイス … 先発11人の**名前ボタンが並び**、1人選ぶと「◯◯が顔を上げた。」
   - 未実行＝ボタン、実行済み＝結果文、未開放＝「まずコーチの話を聞く」等の一行
3. **デュエル状況** … 自チームの選手名＋**対人勝率のバーと％**（現状は10人ぶん並ぶ）
   ＋その下に**コーチのひとこと**（例：「◯◯選手が苦戦しています。対策を検討しましょう。」）
4. **「戦術・システム・選手交代」** … 別画面へ送るボタン1つ
5. **「後半キックオフ」** … 一次アクション

## 直してほしいこと（現状の問題）
- 白いモーダルで、他画面（紺地＋金の二重罫）と**美術が繋がっていない**
- 縦一列に積まれていて、**采配3ステップとデュエル10行でスクロールが要る**
- 「後半キックオフ」が下に押しやられ、**主導線が遠い**
- 采配の3ステップと、デュエル状況（判断材料）が**同じ列に混ざっていて役割が分かれていない**

## 仕上げの指定（H2 と同じUI言語で統一）
- **選手の顔＝ドット/ピクセル頭**（キャプ翼系のドット絵。写実写真は使わない）
  ※顔を出してよいのは③の選手選びと、デュエル状況の行くらい。**新しい情報は増やさない**
- **クラブ徽章・アイコン＝ピクセルアート**／**数字・見出し＝ビットマップ寄り**
- **配色＝紺地＋金の二重罫のフラットな限定パレット**（グロス/グラデは抑える）
- **枠・パネル＝チャンク（太め）なドット縁**＋**薄いCRT/ディザ質感**を全体に薄く
- **白いモーダルはやめて全画面のハーフタイム面にする**
- **スクロールなし・fit-to-screen**。上の5要素だけで画面が埋まる配置にする
- 数値は**デュエル勝率の％以外は作らない**（効果量の「+15%」のような数字を勝手に足さない）

## 出力
- **landscape 1536×864 を1枚**（image_gen）。
- 配置をどう変えたかを **3行以内**で添える。**足した情報が無いこと**も明記すること。
