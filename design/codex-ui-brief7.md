# 依頼（第7弾）：ハーフタイム画面を「中身から」設計し直す

## 添付画像の役割
- **`halftime_current.png`** … **現状の実画面**（作り直す対象）。白いモーダルで縦一列。
- **`H2_season_end_retro.png`** … **"目標の仕上げ"**＝レトロ・ハイブリッドの見本。質感・色・枠・文字はこれに合わせる。

## 今回は「見た目」だけでなく **中身（情報設計）も提案してほしい**
ただ配色を変えるのではなく、**ハーフタイムに監督が本当に見たいものは何か**を考え、
出す情報・順番・粒度から作り直してほしい。要らないものは削ってよい。

## ゲームの前提
- サッカー監督ゲーム。プレイヤーは**監督**で、選手を直接は操作しない。
- 1日1試合。試合は「チャンス（決定機）」の連続として進み、その1つ1つが
  攻撃側選手 vs 守備側選手の**デュエル**で解決される。
- ハーフタイムは**後半に向けて手を打つ唯一の停止点**。ここを外すと後半は流れるだけ。

## いま画面にあるもの（機能としては残す前提。配置と見せ方は変えてよい）
1. **前半終了時のスコア**
2. **ハーフタイムの采配（3ステップ・順番固定・前を済ませるまで次は開かない）**
   - ①コーチから助言をもらう … 相手が前半に最も多く仕掛けた攻め筋を割り出し、後半だけ対策する
   - ②選手を鼓舞する … チーム全体の士気を上げる
   - ③選手個別にアドバイス … 先発11人から1人を選び、その選手の士気を上げ苛立ちを消す
3. **デュエル状況** … 自チーム10人の対人勝率バー＋コーチのひとこと（現状は10行並ぶ）
4. **戦術・システム・選手交代**（別画面へ送るボタン）
5. **後半キックオフ**

## 使えるデータ（これらは実際にゲームが持っている＝画面に出せる）
- 前半の全チャンスの内訳：**攻撃の種別**（ショートパス／ロングパス／ドリブル突破／
  クロス／ポストプレー／飛び出し）と**結果**（ゴール／GKが防いだ／枠を外した／
  ブロック／失敗／カウンター／ファール）。**どちらのチームの攻撃か**も分かる。
- 得点者・アシスト、シュート数・枠内数・決定率、ファール数、警告・退場
- 選手ごとの：対人勝率、士気、苛立ち、**疲労**（出場時間×スタミナ）、軽傷、警告の有無
- 相手が何で攻めてきているかの内訳（＝上の攻撃種別の集計）
- 監督の能力（戦術眼／分析力／モチベーター／フィジカル管理）、クラブの信頼、人気
- 交代枠の残り（5人まで・3回まで）、控え選手の一覧
- 現在の戦術・システム・キープレイヤー・要注意プレイヤー

## 考えてほしい観点
- **監督は後半に何を変えるのか**。その判断に要る情報は何で、いま足りないものは何か。
- 10人ぶんの勝率バーは本当に全部要るか。**苦戦している選手だけ**でよくないか。
- 「誰を替えるべきか」が分かる形になっているか（疲労・警告・不調が見えるか）。
- 相手に何をやられているのかが**一目で**分かるか。
- 采配3ステップは、ここでの主役として正しい置き方か。

## 仕上げの指定（H2 と同じUI言語で統一）
- **選手の顔＝ドット/ピクセル頭**（キャプテン翼系のドット絵。写実写真は使わない）
- **クラブ徽章・アイコン＝ピクセルアート**／**数字・見出し＝ビットマップ寄り**
- **配色＝紺地＋金の二重罫のフラットな限定パレット**（グロス/グラデは抑える）
- **枠・パネル＝チャンク（太め）なドット縁**＋**薄いCRT/ディザ質感**を全体に薄く
- **白いモーダルはやめて全画面のハーフタイム面にする**
- **スクロールなし・fit-to-screen・3ゾーン＋下部コマンドバー**

## 出力
- **landscape 1536×864 を1枚**（image_gen）。
- **どんな情報設計にしたか・何を足して何を削ったか・その理由**を **5行以内**で添える。
