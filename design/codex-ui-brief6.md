# 依頼（第6弾）：試合前「布陣設定画面」を レトロ・ハイブリッド仕上げ で作り直す

## 添付画像の役割
- **`prep_current.png`** … **レイアウトの元＝現行の実画面のスクリーンショット**（作り直す対象）
- **`H2_season_end_retro.png`** … **"目標の仕上げ"** ＝レトロ・ハイブリッドの見本。質感・色・枠・文字はこれに合わせる

## この画面の役割（機能は削らない）
試合直前に**スタメンを組み、システムと戦術を決めて、キックオフする**画面。
現行画面にある要素は**すべて残す**こと：

1. **ヘッダー** … 「← 戻る」／対戦カード見出し（例：イングランド VS ベルギー）
2. **スターティングメンバー（ピッチ図）** … 11人をポジション枠に配置。各選手は
   「ポジション略号（GK/CB/SB/DM/OM/SM/CF …）＋選手名」。**ドラッグで入れ替え**る操作面。
   - **非得意ポジションの選手は警告表示**（現行は⚠アイコン＋「全能力5%ダウン」の注記）
3. **控え（ベンチ）** … 15人前後のカード。各カードに「ポジション略号＋選手名」。
   ここからピッチへドラッグして交代させる。**一覧できること**が要件（スクロール前提にしない）
4. **システム** … 現在値（例 4-2-3-1）を出すボタン
5. **戦術** … 現在値（例 バランス重視）を出すボタン
6. **キープレイヤー** … 自チームの注目選手（例 ベリンガム）
7. **要注意プレイヤー** … 相手の警戒選手（例 ルカク）
8. **キックオフ！** … 最も強い一次アクション

## 直してほしいこと（現行の問題）
- 明るいグレー地＋青いベタボタンで、**他の画面（シーズンハブ／シーズン終了）と美術が繋がっていない**
- **縦に間延びして「キックオフ！」が2回出ている**（上下に重複）。1つに絞る
- 右カラムに**大きな余白**が空き、情報密度が低い
- ピッチ図が小さく、**主役（スタメン編成）に見えない**
- 控えカードで**選手名が折り返して読めない**ものがある（「フォーデン」「ショーン・ダイク」等）

## 仕上げの指定（H2 と同じUI言語で統一）
- **選手の顔＝ドット/ピクセル頭**（キャプテン翼系のドット絵。写実写真は使わない）
- **クラブ徽章・アイコン＝ピクセルアート**
- **数字・見出し＝ビットマップ寄り**（可読性は保つ）
- **配色＝紺地＋金の二重罫のフラットな限定パレット**（グロス/グラデは抑える）
- **枠・パネル＝チャンク（太め）なドット縁**＋**薄いCRT/ディザ質感**を全体に薄く
- **スクロールなし・fit-to-screen**
- **3ゾーン＋下部コマンドバー**の骨格に載せ替える。推奨の割り当て：
  - 左ゾーン＝**ピッチ図（スタメン）**：この画面の主役なので一番大きく
  - 中ゾーン＝**控えベンチ**：グリッドで一覧。名前は1行に収める
  - 右ゾーン＝**システム／戦術／キープレイヤー／要注意プレイヤー**
  - 下部コマンドバー＝**キックオフ！（1つだけ）／戻る／自動編成** 等
- ピッチの緑は**限定色のフラットな芝**（現行のようなツヤは無し）。ラインはドット。

## 出力
- **landscape 1536×864 を1枚**（image_gen）。
- 機能要素の**取りこぼしゼロ**を優先。レイアウトは上記3ゾーンへ組み替えてよいが、
  **要素を削らない・増やさない**。
- どこをどう変えたかを **3行以内** で添える。
