# 依頼（第4弾）：既存レイアウトを「レトロ・ドット絵と整合するハイブリッド仕上げ」に作り直す

前回までのモック（添付）で**レイアウト・情報設計・スクロール廃止・3ゾーン＋下部コマンドバー**は確定。ただし仕上げが**スリックでモダン・写実的な顔**になっており、本作の世界観（**選手・試合中がレトロなドット絵／ピクセルアート**）と**美術的に食い違う**。そこを直したい。

## 本作の実際の画風（これに寄せる）
- 選手・試合中のスプライトは**レトロなドット絵/ピクセルアート**（NES〜キャプテン翼系のドット頭、マンガ絵をピクセル化した劇画コマ）。
- つまりUIも、その**ドット絵の隣に置いて馴染む**見た目にする必要がある。

## やること＝「構成は固定、仕上げだけレトロ化」（ハイブリッド）
添付モックの**レイアウト/構成/要素/情報の配り方は"そのまま"**（同じ3ゾーン・同じ位置・同じ操作バー・スクロールなし・fit-to-screen）。**変えるのは視覚の仕上げだけ**：

- **選手の顔＝写実写真をやめ、ドット/ピクセル・ポートレート**（レトロな顔ドット絵）に。
- **クラブ徽章・アイコン類＝ピクセルアート**（ドット絵の紋章/アイコン）に。
- **書体＝ピクセル/ビットマップ寄り**の見出し（可読性は保つ。日本語はドット風でも潰れない程度に）。数字はレトロなLED/ドット風でも可。
- **配色＝グロス/グラデを抑え、フラットで限定的なパレット**（レトロゲーム的な少数色＋要所のアクセント）。
- **枠・パネル＝角丸を減らしチャンク（太め）な縁**や軽いドット/ディザのテクスチャ。**薄いスキャンライン/CRT感**を全体に薄く乗せてよい（やり過ぎない）。
- ただし**情報密度が高い画面でも読める・操作できる**ことを最優先（レトロ化で潰さない）。「ドット絵の世界の、よく作り込まれたゲームUI」を狙う。
