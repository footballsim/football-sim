# 依頼：サッカー監督ゲーム「試合以外の主要画面」UI設計＋モック画像

あなたは**据置/モバイルの商用ゲームのシニアUIデザイナー**。この作品の**試合パート以外の主要画面**を設計し、各画面の**モック画像**を生成してほしい。まず設計方針を短く述べ、次に image_gen でモック画像を作る。

## 作品
- ジャンル：サッカー**監督キャリア**ゲーム（"デイリーリーグ"）。1日1試合を消化し、14節で1シーズン。
- ループ：架空リーグの**8つの架空クラブ**から1つを選ぶ→毎日1試合を指揮→順位を上げる→シーズン末に会長に評価される→**残留／他クラブからのオファー／解任**を選び次シーズンへ。
- 持続要素：監督の成長パラメータ、クラブからの信頼度、人気、宿敵（ライバル）クラブ。
- **IP安全**：実在クラブの徽章/ロゴ/実選手は不可。架空のクラブ名・シンボルのみ。

## 最重要の制約（ここが今の失敗点）
1. **画面はゲームの固定フレームに"必ず"収める。スクロールしない。** 据置ゲームのメニューのように、1画面で完結させる（情報が多い画面はタブ/ページ送り/ゾーン分割で分ける。"少し下にスクロール"も不可）。**iPhone13を横持ちした低い画面（横長・高さが低い）でも溢れないこと**を前提に設計する。
2. **横長（landscape）レイアウト**。おおむね16:9〜。
3. **テイスト＝上質な商用ゲームUI**（Football Manager / EA Sports FC / NBA 2K のメニュー級の作り込み）。ダーク基調・端正なパネル・控えめな奥行き・要所に金などのアクセント・明確な視覚階層。**マンガ/コミック調は禁止**（それは試合中の演出だけの担当）。
4. 日本語UI（英語も想定＝日本語は字面が長い）。文字は読める余白で。

## 設計してほしい主要画面（各：短い意図＋モック画像1枚）
1. **クラブ選択（シーズン開始）**：8クラブを一望して1つ選ぶ。クラブの徽章・戦力・会長の要求（目標順位）が分かる。
2. **シーズンハブ（進行中の日次ホーム）**：この作品の"毎日開く"中心画面。要素＝次の試合カード（自分 VS 相手・ホーム/アウェイ・相手の軽い偵察情報）／自分の現在順位・勝点／監督ステータス／「今日の試合へ」の主ボタン／サブ情報へのタブ（順位・準備・監督・記録）。**1画面に収める配り方**を提案。
3. **順位表**：8クラブの順位（順位/クラブ/試合/勝分敗/得失点/勝点）。自クラブをハイライト。1画面で一望。
4. **シーズン終了リザルト（最重要・今スクロールで破綻中）**：シーズン末の締め。要素＝優勝クラブ＋自クラブ最終結果＋総評／個人タイトル（得点王・アシスト王・皆勤）／シーズンベストイレブン（11人・顔つき）／クラブの評価（達成/未達・信頼/人気の増減）／**この先の契約選択**（残留／オファー数件／解任）。**これを"スクロールさせずに"どう構成するか**をあなたの判断で（例：ページ送りの祝祭シーケンス、要素の取捨選択、別画面への退避、など）。ベストな枠組みを提案し、代表画面のモックを作る。
