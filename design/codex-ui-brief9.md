# 依頼（第8弾）：ハーフタイム画面 ─ **構成が確定した**ので、その通りに作る

## 添付画像の役割
- **`halftime_current.png`** … 現状の実画面（作り直す対象）
- **`H2_season_end_retro.png`** … **"目標の仕上げ"**＝レトロ・ハイブリッドの見本

## 画面に出すもの（この6つだけ。増やさない・減らさない）

1. **見出し「ハーフタイム」＋前半終了時のスコア**
   例：🏴 イングランド 0 - 0 ベルギー 🇧🇪

2. **両チームの基本スタッツ（対比表示）**
   自チームと相手を左右に並べ、中央に項目名を置く**対比バー**形式。項目は以下の5つだけ：
   - シュート数
   - 決定機
   - ポゼッション（％・左右で合計100）
   - デュエル勝率（％）
   - GKセーブ
   ※ここに出す数字は**この5項目のみ**。パス成功率・走行距離・コーナー・オフサイド等は**作らない**。

3. **コーチの助言（ボタン）**
   押すと結果文が出る：「相手は前半『◯◯』を◯回仕掛けている。後半はここを潰す。」

4. **選手とMTG（ボタン）**
   押すと結果文が出る：「ロッカールームが沸いた。チーム全体の士気が上がった。」

5. **個別アドバイス**
   先発11人の**名前ボタンが並び**、1人選ぶと「◯◯が顔を上げた。」
   ※3→4→5 の順に進む。前を済ませるまで次は開かない（未開放は薄く・鍵の表現）

6. **下部コマンドバー**
   - 「戦術・システム・選手交代」（別画面へ送る）
   - 「試合再開」（一次アクション・最も強く）

## 出してはいけないもの
現状にも上のリストにも無いもの＝**ピッチ図・ヒートマップ・攻め筋の内訳グラフ・
選手ごとのデュエル勝率10行・疲労ゲージ・カード/軽傷/士気アイコン・交代枠の残り・
「現在の後半プラン」・効果量の％（+15% 等）**。1つも描かないこと。

## 仕上げの指定（H2 と同じUI言語で統一）
- **選手の顔＝ドット/ピクセル頭**（キャプ翼系のドット絵。写実写真は使わない）
  ※顔を出してよいのは「個別アドバイス」の選手ボタンだけ
- **クラブ徽章・アイコン＝ピクセルアート**／**数字・見出し＝ビットマップ寄り**
- **配色＝紺地＋金の二重罫のフラットな限定パレット**（グロス/グラデは抑える）
- **枠・パネル＝チャンク（太め）なドット縁**＋**薄いCRT/ディザ質感**を全体に薄く
- **全画面**（白いモーダルは廃止）・**スクロールなし・fit-to-screen**
- 上の6要素だけで画面が過不足なく埋まる配置にすること

## 出力
- **landscape 1536×864 を1枚**（image_gen）。
- 配置の意図を **3行以内**で添える。**指定外の情報を足していないこと**も明記すること。
