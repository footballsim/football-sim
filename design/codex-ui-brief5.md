# 依頼（第5弾）：残りの画面を「レトロ・ハイブリッド仕上げ」に揃える

添付画像のうち **`H2_season_end_retro`（レトロ版）が"目標の仕上げ"** ＝レトロ・ハイブリッドの見本。
それ以外の添付画像は **"レイアウトの元"**（初回のスリック版）。

## やること
各"レイアウトの元"画像を、**レイアウト・構成・要素・位置・情報密度は「そのまま」**に、
**H2 と同じレトロ・ハイブリッド仕上げ**で作り直す：
- **選手の顔＝ドット/ピクセル頭**（キャプテン翼系のドット絵。写実写真は使わない）
- **クラブ徽章・アイコン＝ピクセルアート**
- **数字・見出し＝ビットマップ寄り**（可読性は保つ）
- **配色＝フラットで限定的なパレット**（グロス/グラデは抑える）
- **枠・パネル＝チャンク（太め）なドット縁**＋**薄いCRT/ディザ質感**を全体に薄く
- スクロールなし・fit-to-screen・3ゾーン＋下部コマンドバーは**維持**

## 出力
- 添付の"レイアウトの元"画像それぞれについて、**同じ構図のレトロ版を1枚ずつ** image_gen（landscape 1536×864）。
- **レイアウトは絶対に動かさない**（H2 のように"仕上げだけ"変える）。全部 H2 と同じレトロUI言語で統一。
- どの元画像をどう変えたか、各1行だけ添えてよい。
